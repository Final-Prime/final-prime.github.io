FP:// PUBLICATION PROTOCOL / 04

Identity → State → Evidence → Boundary

A public route must say what the object is, what state it is in, what supports it and where the claim stops.

  1. 01Identity

    Stable title, type and canonical route.

  2. 02State

    Published, active, paused, archived or empty.

  3. 03Evidence

    An inspectable build, image, document or verified result.

  4. 04Boundary

    Explicit limits without implying full-process disclosure.
